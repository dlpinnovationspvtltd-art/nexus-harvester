=======================================================
   NEXUS HARVESTER - WINDOWS DISTRIBUTION PACKAGE
=======================================================

This package contains everything needed to run or generate the standalone
"Nexus Harvester.exe" file for Windows users.

Files in this folder:
1. NexusHarvester.py        -> Complete application source code with all latest updates:
                               - Full Google Places API Harvester & Prospector
                               - Free Groq AI Copywriting Engine (dynamic model detection)
                               - SMTP Outreach & Bulk Campaign Dispatch Deck
                               - Excel & CSV 1-Click Import / Export
                               - Dual-column Send buttons (Individual & Bulk)
2. build_exe.bat            -> 1-click builder script to produce "Nexus Harvester.exe".
3. run_nexus_harvester.bat  -> 1-click script to run the app directly on Windows.
4. requirements.txt         -> Dependencies list (requests, pandas, openpyxl, pycountry, pyinstaller).

-------------------------------------------------------
HOW TO GENERATE "Nexus Harvester.exe":
-------------------------------------------------------
Method A: On ANY Windows PC / Laptop (Takes 2 minutes)
1. Copy this "Nexus Harvester Windows" folder to any Windows computer.
2. Double-click "build_exe.bat".
3. It will automatically install requirements and compile "Nexus Harvester.exe".
4. When finished, you will see "Nexus Harvester.exe" right in the folder.
   This single .exe file is 100% standalone and ready to distribute or sell to buyers!

Method B: Free GitHub Actions Cloud Build (No Windows PC Needed)
If you don't have a Windows PC nearby, you can push this repo to GitHub and use
a free GitHub Actions Windows runner (`runs-on: windows-latest`) to build the
.exe file in the cloud and download the artifact directly.
